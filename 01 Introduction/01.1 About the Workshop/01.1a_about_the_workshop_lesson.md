## How to Use CADET

| Tool              | What it is                                        | Used for                                         |
| ----------------- | ------------------------------------------------- | ------------------------------------------------ |
| **CADET-Core**    | the solver, written in C++                        | solving the model equations, fast and accurate   |
| **CADET-Python**  | a thin Python interface to CADET-Core             | writing and running CADET-Core input files       |
| **CADET-Process** | a Python toolbox for modeling and optimization    | building processes, simulating, optimizing; **most of this workshop** |
| **CADET-GUI**     | interactive widgets on top of CADET-Process       | exploring models in the notebook, without code   |

CADET-Core can also be run on its own: `cadet-cli` reads an HDF5 input file and writes the results into it.

## The Widgets

The early Day 1 lessons build models in CADET-GUI widgets. Binding and reactions use CADET-Process code. Each widget shows **one** CADET-Process object:

| Widget                  | Object                                  |
| ----------------------- | --------------------------------------- |
| `ComponentSystemWidget` | the components                          |
| `UnitOperationsWidget`  | the unit operations and their parameters |
| `FlowSheetWidget`       | the connections between the units       |
| `ProcessWidget`         | cycle time and events                   |
| `SimulationWidget`      | the simulation and its results          |

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

- The widgets edit ordinary Python objects: what you build in a widget, you can use in code, and back.
- **Show code** shows the CADET-Process code for each step.
- They are a way into the code, not a replacement: everything we do in widgets, we also write as code.

## Workshop structure

| Chapter                                  | Focus                          | Topics                                                                                      |
| ---------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------- |
| 02 CADET Fundamentals                    | Building and simulating models | first model, model templates, inlet profiles, residence time distributions, binding         |
| 03 Process Simulation                    | Chromatographic processes      | simple and advanced chromatography                                                          |
| 04 Characterization and Optimization     | Using models                   | optimization essentials, parameter fitting, characterization, fractionation, process optimization |

The first lessons build models in interactive widgets and move step by step to code. From **02.5 Binding** onwards, we work in CADET-Process code; **Show code** from earlier lessons and the [GUI Workbench](../../99%20Misc/99.2%20GUI%20Workbench/) remain available as a fallback.

The chapters build on each other, but each topic can also be worked through on its own. [99.3 Reactions](../../99%20Misc/99.3%20Reactions/) is an optional excursion. Detailed optimization examples are additional material in **99.4–99.5**.

## How to use CADET

| Tool              | What it is                                        | Used for                                         |
| ----------------- | ------------------------------------------------- | ------------------------------------------------ |
| **CADET-Core**    | the solver, written in C++                        | solving the model equations, fast and accurate   |
| **CADET-Python**  | a thin Python interface to CADET-Core             | writing and running CADET-Core input files       |
| **CADET-Process** | a Python toolbox for modeling and optimization    | building processes, simulating, optimizing; **most of this workshop** |
| **CADET-GUI**     | interactive widgets on top of CADET-Process       | exploring models in the notebook, without code   |

CADET-Core can also be run on its own: `cadet-cli` reads an HDF5 input file and writes the results into it.

## The widgets

The first lessons (02.1–02.4) build models in CADET-GUI widgets; later lessons use CADET-Process code. The widgets expose the parts of a CADET-Process model:

| Widget                  | Object                                  |
| ----------------------- | --------------------------------------- |
| `ComponentSystemWidget` | the components                          |
| `UnitOperationsWidget`  | the unit operations and their parameters |
| `FlowSheetWidget`       | the connections between the units       |
| `ProcessWidget`         | cycle time and events                   |
| `SimulationWidget`      | the simulation and its results          |

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

- The widgets edit ordinary Python objects: what you build in a widget, you can use in code, and back.
- **Show code** shows the CADET-Process code for each step, so you can reuse the widget settings in Python.

## Configure a process and show its code

In **System**, choose the instrument layout and open **Process configuration**. Set the components, column model, binding model and process template, then enter the parameters for the example you are working on.

Click **Show code** in **Process configuration** to see the Python code for the current setup. Copy it into a code cell in your exercise notebook, check the values and run it. Use new Python variable names if you want to keep an existing model available.

**Simulation** runs the configured process. **Parameter Estimation** fits model parameters to experimental data by comparing measured signals with simulated results.

## Summary

- Configure the instrument, model parameters and process template in one workspace.
- Simulate the process, inspect the results and use **Show code** to reuse the setup in Python.
- Parameter estimation connects experimental measurements to fitted model parameters.

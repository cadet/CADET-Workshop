```python
# Let's check what packages are currently installed
import subprocess
import sys

def run_pip_command(command):
    """Run a pip command safely"""
    try:
        result = subprocess.run([sys.executable, "-m", "pip"] + command, 
                              capture_output=True, text=True, check=True)
        return result.stdout
    except subprocess.CalledProcessError as e:
        return f"Error: {e.stderr}"

# Check pip version
print(" Current pip version:")
pip_version = run_pip_command(["--version"])
print(pip_version)
```

```python

lines = packages.split('\n')[:12]  # First few lines including headers
for line in lines:
    if line.strip():
        print(line)
```

## Important Scientific Computing Libraries Overview

### NumPy
**NumPy** (Numerical Python) is the foundation of scientific computing in Python. It provides:
- **Fast multidimensional arrays** - Much faster than Python lists for numerical operations
- **Mathematical functions** - Trigonometry, statistics, linear algebra
- **Broadcasting** - Perform operations on arrays of different shapes
- **Memory efficient** - Stores data in contiguous memory blocks

### Matplotlib
**Matplotlib** is Python's primary plotting library:
- **Comprehensive plotting** - Line plots, bar charts, histograms, scatter plots
- **Customizable** - Control every aspect of your plots
- **Publication quality** - Professional figures for reports and papers
- **Multiple backends** - Display in notebooks, save to files, web applications

### Pandas
**Pandas** is built on NumPy and provides high-level data manipulation tools:
- **DataFrames** - 2D labeled data structures (like Excel spreadsheets)
- **Series** - 1D labeled arrays (like a single column)
- **Data I/O** - Read/write CSV, Excel, JSON, SQL databases
- **Data cleaning** - Handle missing values, duplicates, data types

> **Together**: NumPy handles the numerical computations, Pandas manages the data, and Matplotlib visualizes the results - forming the core stack for data analysis in Python.


> **Tip**: In a real project, you'd typically install packages in a terminal


## Virtual Environments

Virtual environments are isolated Python installations that allow you to manage dependencies for different projects separately. This prevents conflicts between different projects' requirements.

### Why Virtual Environments?

```txt
Project A needs:          Project B needs:
- numpy 1.20.0           - numpy 1.24.0  
- pandas 1.3.0           - pandas 2.0.0
- matplotlib 3.5.0       - seaborn 0.12.0

Without virtual environments → CONFLICT!
With virtual environments → No problem
```

### Types of Virtual Environments

1. **venv** (built-in Python tool)
2. **conda** (from Anaconda/Miniconda)

<!-- #region -->
### Working with venv (Built-in)

```bash
# Create virtual environment
python -m venv myproject_env

# Activate environment
# Windows:
myproject_env\Scripts\activate
# macOS/Linux:
source myproject_env/bin/activate

# Install packages in environment
pip install numpy pandas matplotlib

# Deactivate environment
deactivate

# Remove environment (just delete the folder)
rmdir /s myproject_env  # Windows
rm -rf myproject_env    # macOS/Linux
```

### Working with conda

```bash
# Create environment with specific Python version
conda create -n myproject python=3.11

# Create environment with packages
conda create -n dataproject python=3.11 numpy pandas matplotlib

# Activate environment
conda activate myproject

# Install packages
conda install numpy
conda install -c conda-forge seaborn

# List environments
conda env list

# Deactivate environment
conda deactivate

# Remove environment
conda remove -n myproject --all
```
<!-- #endregion -->

```python
# Let's check our current Python environment
import sys
import os

print("🐍 Current Python Environment Information:")
print(f"Python version: {sys.version}")
print(f"Python executable: {sys.executable}")
print(f"Python path: {sys.path[0]}")

# Check if we're in a virtual environment
def in_virtualenv():
    return hasattr(sys, 'real_prefix') or (
        hasattr(sys, 'base_prefix') and sys.base_prefix != sys.prefix
    )

if in_virtualenv():
    print("✅ Running in a virtual environment")
    print(f"Virtual env path: {sys.prefix}")
else:
    print("⚠️  Running in global Python environment")
    print("💡 Consider using a virtual environment for your projects!")

# Show some environment variables
print(f"\nEnvironment info:")
print(f"PATH contains: {len(os.environ.get('PATH', '').split(os.pathsep))} directories")
if 'CONDA_DEFAULT_ENV' in os.environ:
    print(f"Conda environment: {os.environ['CONDA_DEFAULT_ENV']}")
if 'VIRTUAL_ENV' in os.environ:
    print(f"Virtual environment: {os.environ['VIRTUAL_ENV']}")
```

## Matplotlib Plot Types Overview 

Matplotlib offers a comprehensive range of plot types for different data visualization needs. Here's a complete overview:

### Basic Plot Types

#### Line Plots
- **`plt.plot()`** - Connect data points with lines
- **Use cases**: Time series, trends, continuous data
- **Variations**: Multiple lines, different styles, markers

#### Scatter Plots
- **`plt.scatter()`** - Show individual data points
- **Use cases**: Correlations, relationships between variables
- **Features**: Variable sizes, colors, transparency

#### Bar Charts
- **`plt.bar()`** - Vertical bars
- **`plt.barh()`** - Horizontal bars
- **Use cases**: Categorical data, comparisons
- **Variations**: Grouped, stacked, error bars

### Distribution Plots

#### Histograms
- **`plt.hist()`** - Show data distribution
- **Use cases**: Frequency distributions, data exploration
- **Options**: Bins, density, cumulative

#### Box Plots
- **`plt.boxplot()`** - Show quartiles and outliers
- **Use cases**: Statistical summaries, comparing groups
- **Features**: Whiskers, outliers, notches

#### Violin Plots
- **`plt.violinplot()`** - Combine box plot with kernel density
- **Use cases**: Distribution shape and statistics

### Specialized Plots

#### Pie Charts
- **`plt.pie()`** - Show proportions
- **Use cases**: Parts of a whole, percentages
- **Features**: Exploding slices, custom colors

#### Area Plots
- **`plt.fill_between()`** - Filled areas
- **`plt.stackplot()`** - Stacked areas
- **Use cases**: Cumulative data, confidence intervals

#### Heatmaps
- **`plt.imshow()`** - 2D data as colors
- **Use cases**: Correlation matrices, 2D data visualization
- **Features**: Color maps, annotations

### Advanced Plot Types

#### Contour Plots
- **`plt.contour()`** - Contour lines
- **`plt.contourf()`** - Filled contours
- **Use cases**: 3D data on 2D plane, topographic maps

#### 3D Plots
- **`ax.plot3D()`** - 3D line plots
- **`ax.scatter3D()`** - 3D scatter plots
- **`ax.plot_surface()`** - 3D surfaces

#### Polar Plots
- **`plt.polar()`** - Circular coordinate system
- **Use cases**: Directional data, cyclic patterns

#### Stream Plots
- **`plt.streamplot()`** - Vector field visualization
- **Use cases**: Flow fields, gradients

### Statistical Plots

#### Error Bars
- **`plt.errorbar()`** - Show uncertainty
- **Use cases**: Scientific data, confidence intervals

#### Step Plots
- **`plt.step()`** - Step-wise constant functions
- **Use cases**: Discrete changes, cumulative distributions

#### Stem Plots
- **`plt.stem()`** - Discrete data points with stems
- **Use cases**: Digital signals, discrete sequences

### Multi-Plot Layouts

#### Subplots
- **`plt.subplot()`** - Grid of plots
- **`plt.subplots()`** - Create multiple axes
- **Features**: Shared axes, different sizes

#### Inset Plots
- **Zoomed regions**, **detail views**
- **Use cases**: Highlighting specific areas

> **Pro Tip**: Each plot type can be extensively customized with colors, styles, labels, legends, and annotations to create publication-quality figures!

## Exercise 3: Matplotlib Plotting
1. Import the Matplotlib library.
2. Create a heat plot the 2d function $z = \sin(\sqrt{x^2 + y^2})$.
3. Add labels and a title to your plot.

```python tags=["solution"]
# Exercise 3: Matplotlib Plotting - Solution

# 1. Import the Matplotlib library
import matplotlib.pyplot as plt
import numpy as np

print("Exercise 3: Matplotlib Plotting")
print("=" * 40)

# 2. Create a heat plot of the 2D function z = sin(sqrt(x² + y²))

# Create coordinate grids
x = np.linspace(-2*np.pi, 2*np.pi, 100)  # x values from -2π to 2π
y = np.linspace(-2*np.pi, 2*np.pi, 100)  # y values from -2π to 2π
X, Y = np.meshgrid(x, y)  # Create 2D coordinate grids

# Calculate the function z = sin(sqrt(x² + y²))
# This creates a circular wave pattern radiating from the origin
Z = np.sin(np.sqrt(X**2 + Y**2))

print(f"Created 2D function with shape: {Z.shape}")
print(f"Function values range from {Z.min():.3f} to {Z.max():.3f}")

# Create the heat plot
plt.figure(figsize=(12, 10))

# Main heatmap
plt.subplot(2, 2, 1)
im1 = plt.imshow(Z, extent=[-2*np.pi, 2*np.pi, -2*np.pi, 2*np.pi], 
                 cmap='viridis', origin='lower')
plt.colorbar(im1, label='z value')
plt.title('Heatmap: z = sin(√(x² + y²))')
plt.xlabel('x')
plt.ylabel('y')

# Alternative: Using contourf (filled contour plot)
plt.subplot(2, 2, 2)
contour_filled = plt.contourf(X, Y, Z, levels=20, cmap='plasma')
plt.colorbar(contour_filled, label='z value')
plt.title('Filled Contour: z = sin(√(x² + y²))')
plt.xlabel('x')
plt.ylabel('y')

# Contour lines only
plt.subplot(2, 2, 3)
contour_lines = plt.contour(X, Y, Z, levels=15, colors='black', linewidths=0.5)
plt.clabel(contour_lines, inline=True, fontsize=8)
plt.title('Contour Lines: z = sin(√(x² + y²))')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True, alpha=0.3)

# 3D surface plot (bonus)
from mpl_toolkits.mplot3d import Axes3D
ax = plt.subplot(2, 2, 4, projection='3d')
surface = ax.plot_surface(X, Y, Z, cmap='coolwarm', alpha=0.8)
ax.set_title('3D Surface: z = sin(√(x² + y²))')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_zlabel('z')

plt.tight_layout()
plt.show()

# Additional analysis
print(f"\nFunction Analysis:")
print(f"This function represents circular waves radiating from the origin")
print(f"At the center (0,0): z = sin(0) = {np.sin(0)}")
print(f"The pattern repeats every 2π units in radial distance")
print(f"Maximum amplitude: {Z.max():.3f}")
print(f"Minimum amplitude: {Z.min():.3f}")

# Create a simplified version focusing on the main requirements
plt.figure(figsize=(8, 6))

                     cmap='hot', origin='lower')

# 3. Add labels and a title to your plot
plt.title('Heat Plot: z = sin(√(x² + y²))', fontsize=16, fontweight='bold')
plt.xlabel('x coordinate', fontsize=12)
plt.ylabel('y coordinate', fontsize=12)

# Add colorbar with label
colorbar = plt.colorbar(heatmap)
colorbar.set_label('Function value z', fontsize=12)

# Add grid for better readability
plt.grid(True, alpha=0.3, color='white')

# Customize ticks
plt.xticks([-2*np.pi, -np.pi, 0, np.pi, 2*np.pi], 
           ['-2π', '-π', '0', 'π', '2π'])
plt.yticks([-2*np.pi, -np.pi, 0, np.pi, 2*np.pi], 
           ['-2π', '-π', '0', 'π', '2π'])
```

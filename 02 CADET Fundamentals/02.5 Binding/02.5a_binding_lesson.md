# 02.5 Binding

## Contents

**Tools:** CADET-Process (Python).

**Python used:** Model attributes, component arrays, a simple function, curve fitting and plotting.

**Introduces:** `Linear` and `Langmuir` binding, equilibrium, batch uptake data, isotherm fitting, kinetics, competition and capacity.

1. Linear binding
2. Batch uptake data, isotherm fit and simulation

At the core of chromatographic processes are interactions between the components we want to separate and a stationary phase.
These components can be atoms, ions, or molecules of a gas, liquid, or dissolved solids.

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

These interactions can often be described in terms of an adsorption isotherm:

```{note}
**Isotherm:**
An equation that describes how much of a component is bound to the stationary phase or dissolved in the mobile phase.

Valid for a constant temperature (iso-therm).
```

## Example 1: Linear model

The simplest model for adsorption is the [linear model](https://cadet.github.io/master/modelling/binding/linear.html).

The liquid concentration $c$ and bound concentration $q$ are two **model states**. Linear binding transfers material between them:

$$
\frac{dq}{dt} = k_a c - k_d q,
\qquad q_{\mathrm{eq}} = \frac{k_a}{k_d}c.
$$

`adsorption_rate` sets $k_a$, `desorption_rate` sets $k_d$. With `is_kinetic=True`, we follow the transfer over time; `False` assumes binding is already at equilibrium.

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Let us consider a shaking flask experiment in a `CSTR` (without ingoing or outgoing streams).
In it, we add some porous material such that:

- the overall porosity is $0.5$.
- the volume is $1~\text{L}$.

Then, we add a solution of a component with a concentration of $1~\text{mol} \text{m}^{-3}$.

Let us first create a `ComponentSystem` and a `Linear` binding model.

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import ComponentSystem

component_system = ComponentSystem(1)

from CADETProcess.processModel import Linear

binding_model = Linear(component_system, name="linear")
binding_model.parameters
binding_model.is_kinetic = True
binding_model.adsorption_rate = [2]
binding_model.desorption_rate = [1]
```

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

Now create a `Cstr` unit operation with a porosity of 0.5 and a volume of 1 L.

```{code-cell} ipython3
:tags: [solution]

import numpy as np
from CADETProcess.processModel import  Cstr

reactor = Cstr(component_system, name='reactor')
reactor.binding_model = binding_model

reactor.init_liquid_volume = 0.5*1e-3
reactor.const_solid_volume = 0.5*1e-3
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Let's also initialize our `Cstr` with a component concentration of $1~\text{mol} \text{m}^{-3}$.

```{code-cell} ipython3
:tags: [solution]

reactor.c = [1]
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Record both states to see the transfer: `write_solution_bulk` saves liquid concentration $c$ as `sim_results.solution.reactor.bulk`; `write_solution_solid` saves bound concentration $q$ as `sim_results.solution.reactor.solid`. The plots show where the component is, while the total amount stays constant in this closed tank.

```{code-cell} ipython3
:tags: [solution]

reactor.solution_recorder.write_solution_bulk = True
reactor.solution_recorder.write_solution_solid = True
```

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

Now, create a `FlowSheet`, a `Process`, and a `simulator`

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import FlowSheet

flow_sheet = FlowSheet(component_system)

flow_sheet.add_unit(reactor)
```

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import Process

process = Process(flow_sheet, 'process')
process.cycle_time = 10
```

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.simulator import Cadet
simulator = Cadet()
sim_results = simulator.simulate(process)

_ = sim_results.solution.reactor.bulk.plot()
_ = sim_results.solution.reactor.solid.plot()
```

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

### A note on resolution

As can be seen in the figure above, the time resolution is not sufficiently high.
By default, CADET-Process stores 1 sample per second.
To increase the resolution, set the `time_resolution` parameter of the `Simulator`.

```{code-cell} ipython3
:tags: [solution]

simulator.time_resolution = 0.1
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Now, the solution looks much smoother.

```{code-cell} ipython3
:tags: [solution]

sim_results = simulator.simulate(process)

_ = sim_results.solution.reactor.bulk.plot()
_ = sim_results.solution.reactor.solid.plot()
```

## Example 2: From batch uptake data to a binding model

In a **batch uptake experiment**, mix a known liquid volume with a known amount of resin, wait for equilibrium and measure the remaining liquid concentration $c_{eq}$. The amount missing from the liquid is bound to the resin.

With initially unloaded resin, $q_{eq}=(c_0-c_{eq})V_{liquid}/V_{solid}$. Here the two volumes are equal, as in our batch tank, so $q_{eq}=c_0-c_{eq}$.

```{note}
These are synthetic equilibrium data for demonstrating the workflow. Liquid concentrations are per liquid volume; bound concentrations are per solid volume. Both use mol/m³.
```

```{code-cell} ipython3
# Initial and measured equilibrium liquid concentrations from five batch experiments.
import matplotlib.pyplot as plt

c_initial = np.array([0.302, 0.748, 1.510, 2.970, 4.530])
c_equilibrium = np.array([0.10, 0.25, 0.50, 1.00, 1.50])
q_equilibrium = c_initial - c_equilibrium
```

+++ {"slideshow": {"slide_type": "slide"}}

### Fit the isotherm

The Linear isotherm is $q_{eq}=Kc_{eq}$. We fit its slope $K$ to the batch data with [curve_fit](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.html), then overlay the fitted line and the data.

```{code-cell} ipython3
:tags: [solution]

from scipy.optimize import curve_fit

def linear_isotherm(c, K):
    return K * c

fitted_parameters, _ = curve_fit(linear_isotherm, c_equilibrium, q_equilibrium)
K = float(fitted_parameters[0])
print(f"Fitted equilibrium factor K = {K:.2f}")
```

```{code-cell} ipython3
# Compare the batch data with the fitted equilibrium isotherm.
c_plot = np.linspace(0, c_equilibrium.max(), 100)
fig, ax = plt.subplots(figsize=(6, 3))
ax.scatter(c_equilibrium, q_equilibrium, label="Batch uptake data")
ax.plot(c_plot, linear_isotherm(c_plot, K), label=f"Linear fit, K = {K:.2f}")
ax.set_xlabel("Equilibrium liquid concentration / mol/m³")
ax.set_ylabel("Bound concentration / mol/m³")
ax.legend()
fig.tight_layout()
plt.show()
```

+++ {"slideshow": {"slide_type": "slide"}}

### Use the fit in CADET-Process

For `Linear`, $K=k_a/k_d$. We reuse the batch tank from Example 1, set `adsorption_rate` to the fitted $K$ and keep `desorption_rate` at 1 s⁻¹.

```{note}
Equilibrium data determine the ratio of the rates, not how quickly binding occurs. The desorption rate of 1 s⁻¹ is an illustrative choice; uptake measurements over time would be needed to fit the kinetics.
```

```{code-cell} ipython3
:tags: [solution]

# Apply the fitted equilibrium factor and start a fresh batch uptake experiment.
reactor.binding_model.adsorption_rate = [K]
reactor.binding_model.desorption_rate = [1]
reactor.c = [1]
reactor.q = [0]
```

```{code-cell} ipython3
# Simulate uptake with the fitted binding model and show both concentration states.
batch_results = simulator.simulate(process)
_ = batch_results.solution.reactor.bulk.plot()
_ = batch_results.solution.reactor.solid.plot()
plt.show()
```

The time plots show uptake approaching equilibrium; the isotherm plot shows the equilibrium relation used to parameterize the model.

## Example 3: Multi-component Langmuir model

Usually, the linear isotherm can only be assumed for very low solute concentrations.
At higher concentrations, the limited number of available binding sites on the surface of the adsorbent also needs to be considered.
The [Langmuir equation](https://cadet.github.io/master/modelling/binding/multi_component_langmuir.html) takes this into account.

$$q = q_{sat} \cdot \frac{b \cdot c}{1 + b \cdot c} = \frac{a \cdot c}{1 + b \cdot c}$$

With:

- $q_{Sat}$ = saturation loading
- $b$ = equilibrium factor

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Assumptions:

- All of the adsorption sites are equivalent, and each site can only accommodate one molecule.
- The surface is energetically homogeneous.
- Adsorbed molecules do not interact.
- There are no phase transitions.
- At the maximum adsorption, only a monolayer is formed.

For this example, we will introduce a concentration step to the `CSTR`.
We consider two components, both with an initial concentration of $0~\text{mM}$, but with different binding strengths.

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

To start: create a `ComponentSystem`

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import ComponentSystem

component_system = ComponentSystem(2)
```

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import Langmuir

binding_model = Langmuir(component_system, name='langmuir')
binding_model.is_kinetic = False
binding_model.adsorption_rate = [3,1]
binding_model.desorption_rate = [1,1]
binding_model.capacity = [1,1]
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Set up the `processModel`

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import Inlet, Outlet, Cstr

inlet = Inlet(component_system, name='inlet')
inlet.c = [1,1]
inlet.flow_rate = 1e-3

reactor = Cstr(component_system, name='reactor')
reactor.binding_model = binding_model

reactor.init_liquid_volume = 0.5*1e-3
reactor.const_solid_volume = 0.5*1e-3
reactor.c = [0.0, 0.0]
reactor.q = [0.0, 0.0]  # optional

reactor.solution_recorder.write_solution_bulk = True
reactor.solution_recorder.write_solution_solid = True
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Set up the `FlowSheet`

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import FlowSheet

flow_sheet = FlowSheet(component_system)

flow_sheet.add_unit(reactor)
flow_sheet.add_unit(inlet)

flow_sheet.add_connection(inlet,reactor)
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Create a `Process`

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import Process

process = Process(flow_sheet, 'process')
process.cycle_time = 10
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Create a `Simulator` and simulate

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.simulator import Cadet

simulator = Cadet()
simulator.time_resolution = 0.01

sim_results = simulator.simulate(process)

_ = sim_results.solution.reactor.bulk.plot()
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

The two components compete for binding sites. Compare their **bound concentrations over time** to see how their different binding strengths affect uptake.

```{code-cell} ipython3
# Show competitive uptake in the solid phase, alongside the liquid response above.
_ = sim_results.solution.reactor.solid.plot()
plt.show()
```

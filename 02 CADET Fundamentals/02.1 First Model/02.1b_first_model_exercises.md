## Exercise 1: scale up

The dashed `starter t_R` line marks the original retention time (about 126 s) and stays fixed while you change the model.

Use the retention-time formula: $t_R=\varepsilon_t\pi d^2L/(4Q)$.

1. Simulate the starter column. Note when the outlet reaches half the feed concentration.
2. Select `column` and change `diameter` from `0.02` to `0.04` m (2 to 4 cm). Keep the other column settings unchanged. Look at the $t_R$ formula: what flow rate would give the same $t_R$ again? Select `inlet`, enter your prediction in `flow_rate` (m³/s), and click **Run simulation**. Does the breakthrough match the `starter t_R` line?
3. Repeat the same experiment in Python. Set column `diameter` back to `0.02` m and inlet `flow_rate` to `1e-7` m³/s (6 mL/min). Click **Show code** in the **unit editor (Parameters of)** and paste the **complete model setup** into the answer cell. Keep the exported variable names (`component_system`, `inlet`, `column`, `outlet`, `flow_sheet` and `process`) and run it. Then run the supplied simulation and plotting cell: it repeats the diameter and flow changes from the GUI and overlays both curves.

```{code-cell} ipython3
:tags: [solution]

# Model setup copied from Show code in the unit editor.
from CADETProcess.processModel import ComponentSystem, Inlet, LumpedRateModelWithoutPores, Outlet, FlowSheet, Process

component_system = ComponentSystem(["Tracer"])
inlet = Inlet(component_system, "inlet")
inlet.c = [1]
inlet.flow_rate = 1e-7
column = LumpedRateModelWithoutPores(component_system, "column")
column.length = 0.1
column.diameter = 0.02
column.total_porosity = 0.4
column.axial_dispersion = 1e-7
outlet = Outlet(component_system, "outlet")
flow_sheet = FlowSheet(component_system, "flow_sheet")
flow_sheet.add_unit(inlet)
flow_sheet.add_unit(column)
flow_sheet.add_unit(outlet)
flow_sheet.add_connection(inlet, column)
flow_sheet.add_connection(column, outlet)
process = Process(flow_sheet, "tracer")
process.cycle_time = 1200
```

Compare the supplied simulation and plot with the GUI result.

```{code-cell} ipython3
# Simulate the copied baseline, then change diameter and flow rate in Python.
simulator = Cadet()
small = simulator.simulate(process)
column.diameter = 0.04
inlet.flow_rate = 4e-7
large = simulator.simulate(process)
fig, ax = small.solution.outlet.outlet.plot()
_ = large.solution.outlet.outlet.plot(ax=ax)
# Python plots show time in minutes.
_ = ax.axvline(t_R / 60, color="gray", linestyle="--", label="starter t_R")
_ = ax.legend()
```

```{dropdown} Answer
The baseline liquid volume is 12.57 mL, so $t_R \approx 126$ s. Doubling the diameter multiplies the area by four: use 24 mL/min. With the same length, porosity, velocity and dispersion, the two curves overlap.
```

## Exercise 2: what moves the breakthrough?

Set column `diameter` to `0.02` m, `total_porosity` to `0.4`, and inlet `flow_rate` to `1e-7` m³/s (6 mL/min). Predict, then change one parameter at a time:

| Parameter | Starter | Changed value |
|---|---|---|
| Flow rate | 6 mL/min | 3 mL/min |
| Porosity | 0.4 | 0.3 |

Which change delays the front? Compare with $t_R=\varepsilon_tV/Q$.

With these starter settings in the editor, click **Show code** in the **unit editor (Parameters of)** and paste the **complete model setup** into the answer cell. Use a `comparison_` prefix for its variables. Simulate this independent model, then change flow and porosity separately in Python.

```{warning}
Reusing a variable name such as `column` or `process` replaces what that name refers to. To keep the Python model from **Exercise 1** available, rename the variables and all their references in this copied setup:

| Copied name | Name for Exercise 2 |
|---|---|
| `component_system` | `comparison_components` |
| `inlet` | `comparison_inlet` |
| `column` | `comparison_column` |
| `outlet` | `comparison_outlet` |
| `flow_sheet` | `comparison_sheet` |
| `process` | `comparison_process` |

The new process has its own units, so quoted names such as `"column"` can stay the same. Run the full copied setup: `comparison_process = process` alone would refer to the same model.
```

```{code-cell} ipython3
:tags: [solution]

# Configuration copied from the unit editor's Show code, with comparison_ variable names.
from CADETProcess.processModel import ComponentSystem, Inlet, LumpedRateModelWithoutPores, Outlet, FlowSheet, Process

comparison_components = ComponentSystem(["Tracer"])
comparison_inlet = Inlet(comparison_components, "inlet")
comparison_inlet.c = [1]
comparison_inlet.flow_rate = 1e-7
comparison_column = LumpedRateModelWithoutPores(comparison_components, "column")
comparison_column.length = 0.1
comparison_column.diameter = 0.02
comparison_column.total_porosity = 0.4
comparison_column.axial_dispersion = 1e-7
comparison_outlet = Outlet(comparison_components, "outlet")
comparison_sheet = FlowSheet(comparison_components, "flow_sheet")
comparison_sheet.add_unit(comparison_inlet)
comparison_sheet.add_unit(comparison_column)
comparison_sheet.add_unit(comparison_outlet)
comparison_sheet.add_connection(comparison_inlet, comparison_column)
comparison_sheet.add_connection(comparison_column, comparison_outlet)
comparison_process = Process(comparison_sheet, "comparison")
comparison_process.cycle_time = 1200

simulator = Cadet()
fig, ax = simulator.simulate(comparison_process).solution.outlet.outlet.plot()
comparison_inlet.flow_rate = 0.5e-7
_ = simulator.simulate(comparison_process).solution.outlet.outlet.plot(ax=ax)
comparison_inlet.flow_rate = 1e-7  # Restore flow before changing porosity.
comparison_column.total_porosity = 0.3
_ = simulator.simulate(comparison_process).solution.outlet.outlet.plot(ax=ax)
```

```{dropdown} Answer
Halving flow doubles the residence time. Reducing porosity reduces the liquid volume and brings the front forward. A late curve alone cannot identify which parameter is wrong.
```

## Exercise 3 (optional): two columns

Set column `diameter` to `0.02` m, `total_porosity` to `0.4`, and inlet `flow_rate` to `1e-7` m³/s (6 mL/min). Click **Show code** in the **unit editor (Parameters of)** and paste the **complete model setup** into the answer cell, using a `series_` prefix for its variables. Add an identical unit named `column_2` and replace the direct column → outlet connection with column → column_2 → outlet. Predict the breakthrough time, then simulate.

```{code-cell} ipython3
:tags: [solution]

# Configuration copied from the unit editor's Show code, with series_ variable names.
from CADETProcess.processModel import ComponentSystem, Inlet, LumpedRateModelWithoutPores, Outlet, FlowSheet, Process

series_components = ComponentSystem(["Tracer"])
series_inlet = Inlet(series_components, "inlet")
series_inlet.c = [1]
series_inlet.flow_rate = 1e-7
series_column = LumpedRateModelWithoutPores(series_components, "column")
series_column.length = 0.1
series_column.diameter = 0.02
series_column.total_porosity = 0.4
series_column.axial_dispersion = 1e-7
series_outlet = Outlet(series_components, "outlet")
series_sheet = FlowSheet(series_components, "flow_sheet")
series_sheet.add_unit(series_inlet)
series_sheet.add_unit(series_column)
series_sheet.add_unit(series_outlet)
series_sheet.add_connection(series_inlet, series_column)
series_sheet.add_connection(series_column, series_outlet)
series_process = Process(series_sheet, "series")
series_process.cycle_time = 1200

series_second = LumpedRateModelWithoutPores(series_components, "column_2")
series_second.length = 0.1
series_second.diameter = 0.02
series_second.total_porosity = 0.4
series_second.axial_dispersion = 1e-7
series_sheet.remove_connection(series_column, series_outlet)
series_sheet.add_unit(series_second)
series_sheet.add_connection(series_column, series_second)
series_sheet.add_connection(series_second, series_outlet)
_ = Cadet().simulate(series_process).solution.outlet.outlet.plot()
print("Predicted residence time / s:", 2 * 0.4 * np.pi * 0.01**2 * 0.1 / 1e-7)
```

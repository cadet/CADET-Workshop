## The Experiment

A **tracer**, a molecule that does not bind (e.g. acetone or salt), is pumped through a packed column from $t = 0$.
The detector at the outlet records the **breakthrough curve**: the concentration rises from zero to the feed concentration.

| Parameter          | Symbol          | Value | Unit                           |
| ------------------ | --------------- | ----- | ------------------------------ |
| Column length      | $L$             | 10    | $\text{cm}$                    |
| Column diameter    | $d$             | 2     | $\text{cm}$                    |
| Total porosity     | $\varepsilon_t$ | 0.4   | \-                             |
| Axial dispersion   | $D_\text{ax}$   | 1e-7  | $\text{m}^2 \text{s}^{-1}$     |
| Flow rate          | $Q$             | 6     | $\text{mL} \, \text{min}^{-1}$ |
| Feed concentration | $c_\text{feed}$ | 1     | $\text{mol} \, \text{m}^{-3}$  |

CADET works with any consistent units; we use SI units: $6~\text{mL}\,\text{min}^{-1} = 10^{-7}~\text{m}^3\,\text{s}^{-1}$.

## Unit Operations

### Inlet

```{figure} ./resources/inlet_parameters.svg
:width: 90%
```

- `c`: concentration of each component; `flow_rate`: volumetric flow rate $Q$
- Each is a cubic polynomial in time: $c_\text{in}(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3$
- A constant feed only needs $a_0$; $a_1$ gives a linear gradient.

+++ {"slideshow": {"slide_type": "subslide"}, "editable": true}

### Outlet

The sink of the system, without parameters. Here it is our detector.

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

### Column

```{figure} ./resources/column_parameters.svg
:width: 90%
```

- Column volume $V = A L$ with cross-section $A = \pi (d/2)^2$
- Liquid volume $\varepsilon_t V$: the tracer only moves through the liquid.
- **Interstitial velocity** $u = \dfrac{Q}{\varepsilon_t A}$

+++ {"slideshow": {"slide_type": "subslide"}, "editable": true}

### Lumped Rate Model Without Pores (LRM)

All liquid, between and inside the particles, is lumped into $\varepsilon_t$. For a tracer:

$$
\underbrace{\frac{\partial c}{\partial t}}_{\text{accumulation}} = \underbrace{- u \frac{\partial c}{\partial z}}_{\text{convection}} + \underbrace{D_\text{ax} \frac{\partial^2 c}{\partial z^2}}_{\text{axial dispersion}}
$$

| Attribute          | Symbol          | Unit                        | Role                                  |
| ------------------ | --------------- | --------------------------- | ------------------------------------- |
| `length`           | $L$             | $\text{m}$                  | length of the column                  |
| `diameter`         | $d$             | $\text{m}$                  | cross-section, so $u$                 |
| `total_porosity`   | $\varepsilon_t$ | \-                          | liquid fraction, so $u$               |
| `axial_dispersion` | $D_\text{ax}$   | $\text{m}^2\,\text{s}^{-1}$ | mixing along the column               |
| `c`, `q`           |                 | $\text{mol}\,\text{m}^{-3}$ | initial concentrations (default 0)    |

The flow rate is not a column parameter: the column gets it from the units that feed it.
See the [LRM documentation](https://cadet.github.io/master/modelling/unit_operations/lumped_rate_model_without_pores.html).

### Creating the Unit Operations

Create each unit, pick it under **Parameters of**, and enter its parameters:

| Model                                 | Name     | Parameters                                                                 |
| ------------------------------------- | -------- | -------------------------------------------------------------------------- |
| Inlet                                 | `inlet`  | `c`: $a_0 = 1~\text{mol}\,\text{m}^{-3}$<br>`flow_rate`: $10^{-7}~\text{m}^3\,\text{s}^{-1}$ |
| Lumped Rate Model Without Pores (LRM) | `column` | `length`: $0.1~\text{m}$<br>`diameter`: $0.02~\text{m}$<br>`total_porosity`: $0.4$<br>`axial_dispersion`: $10^{-7}~\text{m}^2\,\text{s}^{-1}$ |
| Outlet                                | `outlet` | none                                                                       |

Parameters belong to the unit operations. See the [unit operation documentation](https://cadet-process.readthedocs.io/en/latest/user_guide/process_model/unit_operation.html).

```{code-cell} ipython3
---
slideshow:
  slide_type: subslide
jp-MarkdownHeadingCollapsed: true
---
from cadetgui import UnitOperationsWidget

units = UnitOperationsWidget(components)
units.display()
```

## Flow Sheet

Add the three units, then connect `inlet` → `column` → `outlet`.
See the [flow sheet documentation](https://cadet-process.readthedocs.io/en/latest/user_guide/process_model/flow_sheet.html).

```{code-cell} ipython3
---
slideshow:
  slide_type: subslide
---
from CADETProcess.processModel import FlowSheet
from cadetgui import FlowSheetWidget

flow_sheet_widget = FlowSheetWidget(
    FlowSheet(components.component_system, "flow_sheet"), units=units
)
flow_sheet_widget.display()
```

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

## Process

- Holds the flow sheet; sets the **cycle time** and the **events** (none here).
- Reaches every unit parameter under a **path**, e.g. `flow_sheet.column.length`, as used by events and optimization later.

Set the cycle time to 600 s.

```{code-cell} ipython3
---
slideshow:
  slide_type: subslide
---
from cadetgui import ProcessWidget

process_widget = ProcessWidget(flow_sheet_widget.flow_sheet, name="tracer")
process_widget.display()
```

+++ {"slideshow": {"slide_type": "slide"}, "editable": true}

## Simulation

CADET solves the model and returns the concentration at the inlet and outlet of every unit.
Under **Show**: `inlet` is the feed, `outlet` the breakthrough curve.

```{code-cell} ipython3
---
slideshow:
  slide_type: subslide
---
from cadetgui import SimulationWidget

process = process_widget.process

SimulationWidget(process).display()
```

+++ {"slideshow": {"slide_type": "subslide"}, "editable": true}

The same in code:

```{code-cell} ipython3
from CADETProcess.simulator import Cadet

simulator = Cadet()
simulation_results = simulator.simulate(process)
print(simulation_results.solution)
```

## The Result

The tracer passes the column in

$$
t_R = \frac{\varepsilon_t V}{Q} = \frac{L}{u}
$$

```{code-cell} ipython3
import numpy as np

volume = np.pi * (0.02 / 2)**2 * 0.1
t_breakthrough = 0.4 * volume / 1e-7
print(f"t_R = {t_breakthrough:.0f} s")

fig, ax = simulation_results.solution.outlet.outlet.plot()
_ = ax.axvline(t_breakthrough / 60, color="gray", linestyle="--")
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

It arrives around $t_R$, as a smooth front: axial dispersion smears it out.

## Summary

| Level           | Object                        | Parameters                                                   |
| --------------- | ----------------------------- | ------------------------------------------------------------ |
| Components      | `ComponentSystem`             | the species                                                  |
| Unit operations | `Inlet`                       | `c`, `flow_rate`: cubic polynomials in time                  |
|                 | `LumpedRateModelWithoutPores` | `length`, `diameter`, `total_porosity`, `axial_dispersion`   |
|                 | `Outlet`                      | none                                                         |
| Flow sheet      | `FlowSheet`                   | units and connections                                        |
| Process         | `Process`                     | `cycle_time`, events; unit parameters by path                |

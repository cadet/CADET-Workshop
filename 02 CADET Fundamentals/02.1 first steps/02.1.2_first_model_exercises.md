# First Steps - Exercises

## Exercise 1 (core): Scale-Up

A column with twice the diameter (4 cm instead of 2 cm) and the same length and packing should show the same breakthrough time as the column from the lesson.

1. Predict: which flow rate is needed? Does the shape of the front change?
2. Write a function `breakthrough_process(diameter, flow_rate, total_porosity=0.4)` that builds the process from the lesson for the given values and returns it.
3. Simulate both columns and plot their outlets into one figure.

```{tip}
`plot()` returns the figure and the axes. Pass the axes to the next `plot(ax=ax)` call to draw into the same figure.
```

```{code-cell} ipython3
:tags: [solution]

import numpy as np

from CADETProcess.processModel import (
    ComponentSystem,
    FlowSheet,
    Inlet,
    LumpedRateModelWithoutPores,
    Outlet,
    Process,
)
from CADETProcess.simulator import Cadet


def breakthrough_process(diameter, flow_rate, total_porosity=0.4):
    component_system = ComponentSystem(["Tracer"])

    inlet = Inlet(component_system, "inlet")
    inlet.c = 1
    inlet.flow_rate = flow_rate

    column = LumpedRateModelWithoutPores(component_system, "column")
    column.length = 0.1
    column.diameter = diameter
    column.total_porosity = total_porosity
    column.axial_dispersion = 1e-7

    outlet = Outlet(component_system, "outlet")

    flow_sheet = FlowSheet(component_system, "flow_sheet")
    flow_sheet.add_unit(inlet)
    flow_sheet.add_unit(column)
    flow_sheet.add_unit(outlet)
    flow_sheet.add_connection(inlet, column)
    flow_sheet.add_connection(column, outlet)

    process = Process(flow_sheet, "breakthrough")
    process.cycle_time = 600
    return process


# The cross-section grows 4-fold, so the flow rate must too, to keep the velocity u.
simulator = Cadet()
small = simulator.simulate(breakthrough_process(0.02, 1e-7))
large = simulator.simulate(breakthrough_process(0.04, 4e-7))

fig, ax = small.solution.outlet.outlet.plot()
_ = large.solution.outlet.outlet.plot(ax=ax)
```

```{dropdown} Answer
The cross-sectional area grows by a factor of 4, so the flow rate must grow by 4 as well, to $4 \cdot 10^{-7}~\text{m}^3\,\text{s}^{-1}$ (24 mL/min).
Then the interstitial velocity $u$ and the breakthrough time are the same, and so is the shape of the front: both curves lie on top of each other.
Keeping the linear velocity constant is the basis of chromatography scale-up.
```

## Exercise 2 (core): How Each Parameter Changes the Curve

Starting from the column of the lesson, change one parameter at a time and simulate:

- the flow rate: 3, 6 and 12 mL/min ($0.5$, $1$ and $2 \cdot 10^{-7}~\text{m}^3\,\text{s}^{-1}$),
- the column length: 5, 10 and 20 cm,
- the total porosity: 0.3, 0.4 and 0.5,
- the axial dispersion: $10^{-8}$, $10^{-7}$ and $10^{-6}~\text{m}^2\,\text{s}^{-1}$.

Plot the outlet for each parameter into one figure. Which parameters move the breakthrough, and which change the shape of the front? Compare with $t_R = \varepsilon_t V / Q$.

```{tip}
`copy.deepcopy(process)` creates an independent copy of a process, whose parameters you can change without touching the original.
```

```{code-cell} ipython3
:tags: [solution]

import copy

import matplotlib.pyplot as plt

base = breakthrough_process(0.02, 1e-7)
variations = {
    "flow_sheet.inlet.flow_rate": ("Flow rate / mL min$^{-1}$", [0.5e-7, 1e-7, 2e-7], 6e7),
    "flow_sheet.column.length": ("Length / cm", [0.05, 0.1, 0.2], 100),
    "flow_sheet.column.total_porosity": ("Total porosity", [0.3, 0.4, 0.5], 1),
    "flow_sheet.column.axial_dispersion": ("Axial dispersion / m$^2$ s$^{-1}$", [1e-8, 1e-7, 1e-6], 1),
}

fig, axs = plt.subplots(2, 2, figsize=(10, 6), sharex=True, sharey=True)
for ax, (path, (label, values, scale)) in zip(axs.flat, variations.items()):
    for value in values:
        varied = copy.deepcopy(base)
        unit_name, parameter = path.split(".")[1:]
        setattr(getattr(varied.flow_sheet, unit_name), parameter, value)
        solution = simulator.simulate(varied).solution.outlet.outlet
        ax.plot(solution.time / 60, solution.solution[:, 0], label=f"{value * scale:g}")
    ax.set_title(label)
    ax.set_xlim(0, 6)
    ax.legend()
for ax in axs[1]:
    ax.set_xlabel("time / min")
for ax in axs[:, 0]:
    ax.set_ylabel("c / mol m$^{-3}$")
fig.tight_layout()
plt.show()
```

```{dropdown} Answer
- **Flow rate, length and porosity** move the front, as $t_R = \varepsilon_t V / Q$ predicts: twice the flow rate halves $t_R$, twice the length doubles it, and less porosity means less liquid volume and an earlier breakthrough.
- **Axial dispersion** does not move the front, but changes how sharp it is. We look at it in detail in the lesson on residence time distributions.
```

```{code-cell} ipython3
:tags: [solution]

process = Process(flow_sheet, "two_columns")
process.cycle_time = 600

volume = np.pi * (0.02 / 2)**2 * 0.1
t_breakthrough = 2 * 0.4 * volume / 1e-7

simulation_results = simulator.simulate(process)
outlet_solution = simulation_results.solution.outlet.outlet

fig, ax = outlet_solution.plot()
_ = ax.axvline(t_breakthrough / 60, color="gray", linestyle="--")
```

```{dropdown} Answer
Two columns in series hold twice the liquid volume, so the breakthrough time doubles to about 250 s.
The front is wider than for one column: it has been smeared out over twice the length.
```

## Exercise 4 (stretch): Find the Porosity

A colleague measured a tracer breakthrough on a column with the dimensions from the lesson (10 × 2 cm, $10^{-7}~\text{m}^3\,\text{s}^{-1}$, axial dispersion $10^{-7}~\text{m}^2\,\text{s}^{-1}$), but nobody knows the total porosity of the packing.
The measurement is stored in `resources/measured_breakthrough.csv` (time in s, concentration in mol/m³).

1. Load the data into a `ReferenceIO`, the CADET-Process object for measured data.
2. Read the breakthrough time from the data, the time at which the concentration reaches half of the feed, and estimate the porosity with $t_R = \varepsilon_t V / Q$.
3. Show the data in a `SimulationWidget` together with your model, and adjust the column's `total_porosity` in the `UnitOperationsWidget` until the simulation matches the measurement.

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.reference import ReferenceIO

data = np.loadtxt("resources/measured_breakthrough.csv", delimiter=",", skiprows=1)
reference = ReferenceIO("measured", data[:, 0], data[:, 1])

volume = np.pi * (0.02 / 2)**2 * 0.1
t_half = np.interp(0.5, data[:, 1], data[:, 0])
total_porosity = t_half * 1e-7 / volume
print(f"Breakthrough time: {t_half:.0f} s, porosity: {total_porosity:.2f}")

process = breakthrough_process(0.02, 1e-7, total_porosity=total_porosity)
```

```{code-cell} ipython3
from cadetgui import SimulationWidget, UnitOperationsWidget

UnitOperationsWidget(process.component_system, units={"column": process.flow_sheet.column}).display()
SimulationWidget(process, reference=reference).display()
```

```{dropdown} Answer
The measured curve reaches half of the feed concentration after about 110 s, so $\varepsilon_t \approx 0.35$.
With this value, the simulation matches the measurement.
Finding model parameters by comparing simulations with measurements is called **parameter estimation**. On Day 2, we let an optimizer do it.
```

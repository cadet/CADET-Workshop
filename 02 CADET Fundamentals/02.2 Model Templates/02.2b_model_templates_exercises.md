## Exercise 2 (core): export and change the code

1. Select Breakthrough, feed 1 mol/m³ and duration 600 s. Run the GUI simulation.
2. Paste the configuration panel's **Show code** into the answer cell and run it. Then run the supplied simulation cell and compare the curves.
3. In the copied `Breakthrough(...)` call, change `flow_rate` from `1e-7` to `2e-7` m³/s. Predict, then simulate.

`LCFlowSheet(...)` builds the instrument. `Breakthrough(...)` sets its feed, flow and duration.

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import ComponentSystem, LumpedRateModelWithoutPores, Linear
from CADETProcess.instruments import LCFlowSheet, Breakthrough

component_system = ComponentSystem(["Tracer"])
flow_sheet = LCFlowSheet(
    component_system, ColumnModel=LumpedRateModelWithoutPores, BindingModel=Linear,
    bypass_units=["mixer", "tubing_pre_injection", "tubing_pre_column",
                  "tubing_post_column", "tubing_detectors"],
)
flow_sheet.column.length = 0.1
flow_sheet.column.diameter = 0.02
flow_sheet.column.total_porosity = 0.4
flow_sheet.column.axial_dispersion = 1e-7
flow_sheet.column.binding_model.adsorption_rate = [0]
flow_sheet.column.binding_model.desorption_rate = [1]
process = Breakthrough("tracer", flow_sheet, c_sample=[1], flow_rate=1e-7, cycle_time=600)
```

```{code-cell} ipython3
from CADETProcess.simulator import Cadet
simulation_results = Cadet().simulate(process)
_ = simulation_results.solution.outlet.outlet.plot()
```

```{dropdown} Answer
GUI and exported code reproduce the same curve. Doubling the flow from 6 to 12 mL/min halves the column residence time, from about 126 to 63 s.
```

## Exercise 3 (core): complete a Python model

```{note}
This partly configured tracer model has an inlet, column and outlet, but no connections or process yet. Work only in Python.
```

Run the starter and inspect `missing_parameters`. Complete the model using:

| Setting | Value |
|---|---:|
| Feed concentration | 1 mol/m³ |
| Flow rate | `1e-7` m³/s (6 mL/min) |
| Column length | 0.1 m |
| Column diameter | 0.02 m |
| Porosity | 0.4 |
| Axial dispersion | `1e-7` m²/s |
| Cycle time | 600 s |

Some values are supplied already. Set the remaining values, connect inlet → column → outlet and create a `Process` named `completed_tracer`.

```{code-cell} ipython3
from CADETProcess.processModel import (
    ComponentSystem, Inlet, LumpedRateModelWithoutPores, Outlet, FlowSheet, Process,
)

exercise_components = ComponentSystem(["Tracer"])
exercise_inlet = Inlet(exercise_components, "inlet")
exercise_inlet.c = [1]
exercise_column = LumpedRateModelWithoutPores(exercise_components, "column")
exercise_column.length = 0.1
exercise_column.diameter = 0.02
exercise_outlet = Outlet(exercise_components, "outlet")

print("inlet missing:", exercise_inlet.missing_parameters)
print("column missing:", exercise_column.missing_parameters)
print("outlet missing:", exercise_outlet.missing_parameters)
```

```{tip}
Use Part 3 of the lesson as a code reference to complete the next cell. Check the supplied values too: an empty missing-parameter list only means all required values are set.
```

```{code-cell} ipython3
:tags: [solution]

exercise_inlet.flow_rate = 1e-7
exercise_column.total_porosity = 0.4
exercise_column.axial_dispersion = 1e-7

exercise_flow_sheet = FlowSheet(exercise_components, "flow_sheet")
exercise_flow_sheet.add_unit(exercise_inlet)
exercise_flow_sheet.add_unit(exercise_column)
exercise_flow_sheet.add_unit(exercise_outlet)
exercise_flow_sheet.add_connection(exercise_inlet, exercise_column)
exercise_flow_sheet.add_connection(exercise_column, exercise_outlet)

completed_tracer = Process(exercise_flow_sheet, "completed_tracer")
completed_tracer.cycle_time = 600
```

Check that no required parameters are missing.

```{code-cell} ipython3
print("inlet missing:", exercise_inlet.missing_parameters)
print("column missing:", exercise_column.missing_parameters)
print("outlet missing:", exercise_outlet.missing_parameters)
```

The completed model's breakthrough should match the original 6 mL/min tracer experiment.

```{code-cell} ipython3
from CADETProcess.simulator import Cadet
completed_results = Cadet().simulate(completed_tracer)
_ = completed_results.solution.column.outlet.plot()
```

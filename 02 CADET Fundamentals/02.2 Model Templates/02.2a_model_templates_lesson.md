## From the Instrument to a Model

A liquid chromatography system usually has:
- pumps for the buffers A and B (and a feed inlet),
- a mixer, which blends the buffers,
- a sample loop, through which the sample is injected,
- tubing before and after the column, and to the detectors,
- the column and the outlet.

CADET-Process models such a system as an `LCFlowSheet`.
Each part is a unit operation; parts we do not need can be **bypassed**.

## Part 1: configure the instrument

The process configuration sets up such a system in one widget: the column model, the binding model and the **process template**.
Enter `Tracer` in **Components** and keep only the column active. Choose `LumpedRateModelWithoutPores` as the column model and `Linear` as the binding model. Set the following values to reproduce the first experiment:

| Settings | Values |
|---|---|
| Column | length `0.1` m, diameter `0.02` m, total porosity `0.4`, axial dispersion `1e-7` m²/s |
| Binding | equilibrium (`is_kinetic = False`), adsorption rate `[0]`, desorption rate `[1]` |
| Process template | Breakthrough |
| Sample and method | `c_sample = [1]` mol/m³, `flow_rate = 1e-7` m³/s, `cycle_time = 600` s |

Zero adsorption makes this a nonbinding tracer. Keep the mixer and tubing bypassed; the sample loop is used only by templates that need it.

### Process templates

A process template is a standard experiment with a few settings:

| Template | What happens | Seen in |
|---|---|---|
| Breakthrough | the sample is fed continuously | the first model |
| Pulse Injection | a short pulse of sample from the sample loop | tracer and dextran pulses |
| Step | the inlet switches from buffer A to buffer B | system response, RTD |
| Load–Wash–Elute (LWE) | load the sample, wash, elute with a gradient, wash again | binding, chromatography |
| Step Elution | like LWE, but elution in a step | chromatography |

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

Switch from Breakthrough to Pulse Injection and keep its suggested settings. The sample loop becomes active, and the timeline shows a short injection instead of continuous feeding. Select LWE to see its load, wash and elution phases; we will build those inlet changes in the next lesson.

## Part 2: export and run the code

Return to **Breakthrough** and restore the settings from Part 1. Keep only the column active and click **Run simulation**; this is the tracer curve we will reproduce in Python.

Click **Show code**.
The script rebuilds the same `LCFlowSheet` and calls the template class with the settings from the widget.
Paste it into the next cell:

```{code-cell} ipython3
:tags: [solution]

from CADETProcess.processModel import ComponentSystem, LumpedRateModelWithoutPores, Linear
from CADETProcess.instruments import LCFlowSheet, Breakthrough

component_system = ComponentSystem(["Tracer"])
flow_sheet = LCFlowSheet(
    component_system, ColumnModel=LumpedRateModelWithoutPores, BindingModel=Linear,
    bypass_units=["mixer", "tubing_pre_injection", "tubing_pre_column",
                  "tubing_post_column", "tubing_detectors"],
)
flow_sheet.column.length = 0.1
flow_sheet.column.diameter = 0.02
flow_sheet.column.total_porosity = 0.4
flow_sheet.column.axial_dispersion = 1e-7
flow_sheet.column.binding_model.adsorption_rate = [0]
flow_sheet.column.binding_model.desorption_rate = [1]
process = Breakthrough("tracer", flow_sheet, c_sample=[1], flow_rate=1e-7, cycle_time=600)
```

```{code-cell} ipython3
simulation_results = Cadet().simulate(process)
_ = simulation_results.solution.column.outlet.plot()
```

## Part 3: build a process in Python

Rebuild the tracer experiment without widgets or a template. Create the units, inspect their parameters, then connect and simulate them.

```{tip}
Run each cell with **Shift+Enter**. Attribute assignments such as `column.length = 0.1` configure the model directly.
```

+++

### Create the units

```{code-cell} ipython3
from CADETProcess.processModel import (
    ComponentSystem, Inlet, LumpedRateModelWithoutPores, Outlet, FlowSheet, Process,
)

python_components = ComponentSystem(["Tracer"])
python_inlet = Inlet(python_components, "inlet")
python_column = LumpedRateModelWithoutPores(python_components, "column")
python_outlet = Outlet(python_components, "outlet")
```

### Inspect the parameters

```{note}
`required_parameters` lists what a unit needs. `missing_parameters` lists values that have not been set. Defaults can already satisfy some requirements.
```

```{code-cell} ipython3
for unit in (python_inlet, python_column, python_outlet):
    print(unit.name, "requires:", unit.required_parameters)
    print(unit.name, "missing:", unit.missing_parameters)
```

### Set the values

Use the same column and feed as before. A tracer has no binding model.

```{code-cell} ipython3
python_inlet.c = [1]  # mol/m³
python_inlet.flow_rate = 1e-7  # 6 mL/min
python_column.length = 0.1  # m
python_column.diameter = 0.02  # m
python_column.total_porosity = 0.4
python_column.axial_dispersion = 1e-7  # m²/s

for unit in (python_inlet, python_column, python_outlet):
    print(unit.name, "missing:", unit.missing_parameters)
```

### Connect the units and create the process

Connections define inlet → column → outlet. The process adds the experiment duration.

```{code-cell} ipython3
python_flow_sheet = FlowSheet(python_components, "flow_sheet")
for unit in (python_inlet, python_column, python_outlet):
    python_flow_sheet.add_unit(unit)
python_flow_sheet.add_connection(python_inlet, python_column)
python_flow_sheet.add_connection(python_column, python_outlet)

python_process = Process(python_flow_sheet, "python_tracer")
python_process.cycle_time = 600
```

### Simulate and plot

```{code-cell} ipython3
from CADETProcess.simulator import Cadet

python_results = Cadet().simulate(python_process)
_ = python_results.solution.column.outlet.plot()
```

## What We Take Forward

- `LCFlowSheet` represents the instrument; bypassing parts isolates the column.
- A process template describes a standard laboratory experiment using a few settings.
- Export gives the same instrument and recipe as CADET-Process code.
- In Python, create units, check missing parameters, set values and connect them.

### Inlet and outlet

The `Inlet` supplies liquid at concentration `c` and flow rate `flow_rate` (see the [Inlet reference](https://cadet-process.readthedocs.io/en/latest/reference/generated/CADETProcess.processModel.Inlet.html)).
Events can change either parameter during the process.
Here, the flow rate is fixed at $1~mL \cdot s^{-1}$ ($10^{-6}~m^3 \cdot s^{-1}$); the concentration is set by events.

The `Outlet` collects whatever reaches it.

In the unit editor, choose **Model** `Inlet`, set **Name** to `inlet` and click **Create**; repeat with `Outlet` named `outlet`. Select `inlet` under **Parameters of**, set `flow_rate` to `1e-6` m³/s and both constant concentrations to zero. Events will define the feed; the outlet needs no settings.

## Part 1: load, wash and elution

Build this inlet profile: **load** with **50 mM salt** and **1 mM protein** for **60 s**. Then **wash** with **50 mM salt** for **30 s**, stopping the protein feed (**0 mM protein**). **Elute** by increasing salt linearly from **50 to 500 mM** over **60 s**, still with **0 mM protein**. Finish with a **final wash** for **30 s** at **500 mM salt**, without protein.

Set `cycle_time` to **180 s**. Each change starts an event; the following steps translate this method into event times and concentration values.

### Load and wash

Add these two events, setting Salt and Protein to the constant values below; leave their slope and higher coefficients zero. Concentrations are in mM (equivalent to mol/m³).

| Event | Time / s | Salt | Protein |
|---|---:|---:|---:|
| load | 0 | 50 | 1 |
| wash | 60 | 50 | 0 |

Inspect the timeline: the protein concentration drops to zero when washing starts, while salt stays at 50 mM.

### Elution gradient and final wash

During elution, raise salt from 50 to 500 mM over 60 s. The slope is $(500-50)/60 = 7.5$ mM/s.

Add `elute` at 90 s. In its polynomial editor, set Salt's start value $a_0 = 50$ and slope $a_1 = 7.5$; leave $a_2$ and $a_3$ at zero and Protein at zero. Add `final_wash` at 150 s with constant Salt 500 and Protein zero, so the salt stops rising.

| Event | Time / s | Salt | Protein |
|---|---:|---|---:|
| elute | 90 | start 50, slope 7.5 | 0 |
| final_wash | 150 | constant 500 | 0 |

```{note}
The polynomial uses time since its event: $c(t)=a_0+a_1(t-t_e)+a_2(t-t_e)^2+a_3(t-t_e)^3$. The next event starts a new polynomial.
```

Inspect the complete timeline: the salt rises during elution and stays at 500 mM during the final wash.

For each event, click **New event**, enter its name and time from the event tables, select `flow_sheet.inlet.c` and click **Add event**. To edit an existing event, select its row and use **Save changes**.

## Part 2: reproduce the profile in Python

Run the supplied setup cell to create an independent inlet-to-outlet model with initial concentrations `[0, 0]`. Then copy the process and its four events from **Show code** in the process editor.

```{tip}
An event call is `add_event(name, parameter_path, state, time)`. `[50, 1]` sets constant Salt/Protein concentrations; `[[50, 7.5], [0]]` sets a linear salt gradient and zero protein.
```

```{code-cell} ipython3
from CADETProcess.processModel import ComponentSystem, Inlet, Outlet, FlowSheet, Process

python_components = ComponentSystem(["Salt", "Protein"])
python_inlet = Inlet(python_components, "inlet")
python_inlet.flow_rate = 1e-6  # 1 mL/s
python_inlet.c = [0, 0]
python_outlet = Outlet(python_components, "outlet")
python_flow_sheet = FlowSheet(python_components, "flow_sheet")
python_flow_sheet.add_unit(python_inlet)
python_flow_sheet.add_unit(python_outlet)
python_flow_sheet.add_connection(python_inlet, python_outlet)
```

```{tip}
Click **Show code** in the process editor and paste the code into the answer cell. Use `python_flow_sheet` in the `Process(...)` call and `lwe_process` as the Python variable name throughout. Keep the quoted event paths (`"flow_sheet.inlet.c"`) unchanged, then run the cell with **Shift+Enter**.
```

```{code-cell} ipython3
:tags: [solution]

lwe_process = Process(python_flow_sheet, "lwe_python")
lwe_process.cycle_time = 180
lwe_process.add_event("load", "flow_sheet.inlet.c", [50, 1], 0)
lwe_process.add_event("wash", "flow_sheet.inlet.c", [50, 0], 60)
lwe_process.add_event("elute", "flow_sheet.inlet.c", [[50, 7.5], [0]], 90)
lwe_process.add_event("final_wash", "flow_sheet.inlet.c", [500, 0], 150)
```

## Additional example: inlet profiles from data

For a measured or irregular inlet profile, `add_concentration_profile()` accepts arrays of times and concentrations. This example uses a synthetic profile with noise:

```{code-cell} ipython3
import numpy as np
import matplotlib.pyplot as plt

def noisy_inlet(t, seed=0):
    r = np.random.default_rng(seed)
    s = np.exp(-0.5*((t-30)/5)**2) + 0.7*np.exp(-0.5*((t-80)/9)**2)
    d = 0.03*np.sin(2*np.pi*0.02*t)
    n = r.normal(0, 0.02, t.size)*10
    k = np.exp(-np.abs(np.arange(-15, 16))/5)
    y = np.convolve(n, k, 'same')/k.sum()
    return np.clip(s + d + y, 0, None)

t = np.linspace(0, 120, 100)
c = noisy_inlet(t).reshape(-1, 1)

plt.plot(t, c)
plt.xlabel("Time / s")
plt.ylabel("Protein concentration / mol/m³")
```

+++ {"slideshow": {"slide_type": "fragment"}, "editable": true}

For this example, salt stays at zero; only protein follows the supplied data. A fresh model keeps this profile separate from the LWE example. Pass the inlet name, time array, concentration array and component name to `add_concentration_profile()`.

```{code-cell} ipython3
# Create a fresh inlet-to-outlet model with zero salt and protein concentrations.
profile_components, profile_units, profile_sheet, _ = empty_model("profile")
populate_inlet_model(profile_components, profile_units, profile_sheet)
```

```{code-cell} ipython3
:tags: [solution]

profile_process = Process(profile_sheet, 'profile')
profile_process.cycle_time = 120
profile_process.add_concentration_profile('inlet', t, c, components=['Protein'])
```

```{code-cell} ipython3
# Plot the data-derived profile on the same time scale as the input data.
_ = profile_process.plot_events(x_axis_in_minutes=False)
```
